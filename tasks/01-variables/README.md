## Concepts

### Data Types
In JavaScript, we work with several basic data types:
- **String**: Text wrapped in quotes (e.g., `'Hello'`, `"World"`).
- **Number**: Numeric values (e.g., `42`, `3.14`).
- **Boolean**: Logical values representing true or false (e.g., `true`, `false`).
- **Null**: Represents the intentional absence of any object value (`null`).

### `typeof` Operator
You can check the type of a value using the `typeof` operator.
```javascript
typeof 'hello' // returns 'string'
typeof 10      // returns 'number'
typeof true    // returns 'boolean'
```
