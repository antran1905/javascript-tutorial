# Task 02: Strings

In this task, we will manipulate text by learning about JavaScript string properties and methods.

## Concepts

### String Properties
Strings have a `.length` property that tells you how many characters are in the string.
```javascript
'hello'.length // 5
```

### String Methods
Strings have many useful methods. Here are a few you might need:
- `.toLowerCase()` / `.toUpperCase()`: Change the casing of the string.
- `.slice(startIndex, endIndex)`: Extract a section of a string.
- `.split(separator)`: Split a string into an array of substrings.
- `.charAt(index)` or `string[index]`: Access a character at a specific position.

### Useful Array Methods for Strings
Sometimes you need to convert a string to an array to manipulate it, then convert it back!
- `.split('')`: Converts a string to an array of characters.
- `.reverse()`: Reverses an array.
- `.join('')`: Joins an array back into a string.
