# Task 03: Numbers & Math

This task focuses on mathematical operations and the `Math` object in JavaScript.

## Concepts

### Basic Operators
- `+` (addition)
- `-` (subtraction)
- `*` (multiplication)
- `/` (division)
- `%` (modulo / remainder): Returns the remainder of division. For example, `10 % 3` is `1`. This is very useful for checking if a number is even!

### The `Math` Object
JavaScript has a built-in `Math` object with useful methods:
- `Math.min(a, b)`: Returns the smallest number.
- `Math.max(a, b)`: Returns the largest number.
- `Math.round(x)`: Rounds to the nearest integer.

### Number Methods
To round a number to a specific number of decimal places and get a number back, you can use a combination of math or string methods:
- `Number(num.toFixed(decimals))` 
- Or use `Math.round(num * factor) / factor`
