# Task 06: Functions

Functions are one of the fundamental building blocks in JavaScript. A function is a reusable block of code designed to perform a particular task.

## Concepts Covered

- **Basic Functions**: Declaring and calling functions.
- **Default Parameters**: Providing fallback values for parameters.
- **Rest Parameters**: Using `...` to collect multiple arguments into an array.
- **Callbacks**: Passing a function as an argument to another function.
- **Returning Functions**: A function can return another function (creating a closure).
