# Task 07: Arrow Functions

Arrow functions offer a shorter syntax for writing function expressions and do not bind their own `this` context.

## Concepts Covered

- **Arrow Function Syntax**: `(param1, param2) => { return result; }` or `param => result` (implicit return).
- **Array Methods**: Using arrow functions gracefully with methods like `filter` and `sort`.

## Instructions

Complete the variables in `solution.js` by assigning them arrow functions as described.
