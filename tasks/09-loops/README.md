# Task 09: Loops

Loops can execute a block of code a number of times. They are handy if you want to run the same code over and over again, each time with a different value.

## Concepts Covered

- **`for` Loop**: Loops through a block of code a number of times.
- **`while` Loop**: Loops through a block of code while a specified condition is true.

## Instructions

Complete the functions in `solution.js`. Use traditional loops (`for`, `while`) as required rather than built-in string/array methods where instructed.
