# Task 10: Scope & Hoisting

Understanding how scope works is crucial in JavaScript. Scope determines the accessibility of variables.

## Concepts Covered

- **Global vs Local Scope**: Where variables can be accessed.
- **Block Scope**: `let` and `const` variables are block-scoped.
- **Closures**: Functions that have access to their outer scope even after the outer function has returned.
- **Hoisting**: Variable and function declarations are moved to the top of their scope.
