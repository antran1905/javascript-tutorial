# Task 11: Array Methods

Learn to manipulate arrays using built-in methods like `.map()`, `.filter()`, `.reduce()`, `.find()`, `.every()`, and `.sort()`.

- **map**: Transforms elements.
- **filter**: Keeps elements passing a test.
- **reduce**: Reduces array to a single value.
- **find**: Finds first matching element.
- **every**: Checks if all elements match.
- **sort**: Sorts an array in place (but we want you to return a new sorted array).

Open `solution.js` and implement the functions.
